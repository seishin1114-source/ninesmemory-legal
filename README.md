# ninesmemory-legal

iOS アプリ **ナインメンズモリス**（英語名 Mill） の法務・サポートページ。GitHub Pages で公開している。

- 日本語: https://seishin1114-source.github.io/ninesmemory-legal/
- English: https://seishin1114-source.github.io/ninesmemory-legal/en/

内容の原本は本体リポジトリの `AppStore/legal/` にある。**編集はそちらで行い、
`AppStore/legal/publish.sh` を実行して反映する**（このリポジトリを直接編集しない）。
